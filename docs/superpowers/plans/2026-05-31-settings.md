# Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persisted theme and language settings with a lightweight dictionary-based localization layer.

**Architecture:** Add pure settings resolution helpers, a Zustand settings store, and a typed i18n dictionary. Apply the resolved theme on the root HTML element and translate current static React UI strings through a small `useI18n` helper.

**Tech Stack:** React, TypeScript, Zustand, Tailwind class dark mode, Vitest for pure helper tests.

---

## File Structure

- Create `src/lib/settings.ts`: pure preference validators and theme/language resolution helpers.
- Test `src/lib/settings.test.ts`: TDD coverage for language fallback, system language normalization, theme resolution, and invalid stored preferences.
- Create `src/stores/settings-store.ts`: persisted app settings and actions.
- Create `src/lib/i18n.ts`: language metadata, dictionary, translation helper hook.
- Create `src/components/dialogs/settings-dialog.tsx`: settings UI.
- Modify `src/main.tsx`: initialize settings before React renders.
- Modify `src/App.tsx`: apply theme hook, pass translated strings to dialogs, localize prompts/toasts.
- Modify React components under `src/components`: replace current static UI copy with `useI18n`.
- Modify `package.json` and `pnpm-lock.yaml`: add Vitest and a test script.
